# S1 基础设施与算力平台前端

基于 `demo-biz` 前端模板重建的 Vue 3 + TypeScript + Vite + Ant Design Vue 原型。当前仅使用本地虚构数据，不连接真实 API。

导航沿用旧 S1 原型：左侧“平台视图 / 区域资源”两组、九个模块、31 个菜单页面，当前模块展开子菜单。顶部保留页面搜索和账号入口，不展示面包屑；页面内也不展示面包屑，以侧栏高亮和页面标题标识当前位置；区域选择保留在侧栏底部。`src/router/navigation.js` 是导航与详情归属的唯一真源，页面 ID 保留。路由按模块分发到 `src/views/<模块>/index.vue`。

## 迁移进度（2026-10-14）

- 已迁移：全部 9 个模块的 31 个菜单页面，以及对应详情页。
- 公共组件：`common/components/ObjectList.vue`（列表）、`ObjectDetail.vue`（详情）、`PlanModal.vue`（本地预检弹窗）；数据适配与表单逻辑分别位于 `src/common/utils/`。
- 排除（按需求不迁移）：技术方案弹窗与批注功能。
- 详情 ID 使用 URL 查询参数 `id`；未知 ID 显式展示 404，不回退到其他对象。
- 预检只生成本地计划，不更新业务状态、不执行基础设施操作；环境申请向导只生成匹配预检，不创建预留。
- 对象 ID 与旧原型有偏差的地方：平台服务按“服务”列定位（旧“平台”列有重复值）；列头与字段映射按列名修正，详见各模块 `src/common/utils/*.js` 注释。

全部数据为固定示例，不代表真实联调结果；未采集的指标显式标为“未知/未接入”，不推断为正常。旧 React 独立仓库 `prototypes/s1-platform/` 仅作只读参考。

## 流程交互调整（2026-10-14）

- 交付单详情首屏展示当前记录阶段、原因、建议处理方与下一步。拒绝、取消、过期停在原阶段，不把未执行阶段画成完成；已释放单展示回收结果。申请、分配、交付、运行和释放明细按阶段折叠，已有证据不会因阶段尚未推进而隐藏。
- 创建集群采用“机房与模板 → 节点与角色 → 网络 / 存储 / GPU → 预检与本地计划”向导，持续显示已选摘要。候选节点来自已有资产，跨机房、占用、任务中、未知健康、维护或退役均不可选；修改机房或模板会清除节点选择，修改配置后旧计划与知情确认失效。
- 自动本地检查、真实环境验证和人工知情确认分别呈现。当前机房 A 没有空闲已装机节点，机房 B 只有 bm-03 一台，无法满足独立控制面与工作节点要求；可浏览后续步骤，但勾选确认不能解除节点不足的阻塞，也不会生成创建成功记录。
- 任务快速查看抽屉接入任务列表、交付单、资产和集群详情，关闭后保留原页面上下文；任务列表保留搜索、筛选与分页。抽屉提供完整详情入口，重检成功仍保留历史失败日志；S2 模型部署仅只读跟踪，无证据不借用其他任务步骤，不虚构耗时。
