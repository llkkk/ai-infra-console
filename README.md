# S1 基础设施与算力控制台原型

2026-10-10。React + Vite + Lucide 图标，本地低保真产品讨论原型。业务数据全部虚构，无真实 API、服务器操作或凭据。

## 运行与验证

在本目录执行 `pnpm install`，然后 `pnpm dev --host 127.0.0.1`；访问 http://127.0.0.1:8871 。验证：`pnpm build`、`pnpm test`。不以仓库根目录为静态服务根目录。停止服务按 Ctrl+C。

## 页面

覆盖基础设施接入、集群与算力、资源与交付、运行保障、基础服务和平台治理：资产/BMC/硬件能力/装机任务；集群/集群能力/节点/GPU/模板；资源池/配额/分配/环境申请/交付环境/工作负载；监控/告警；接入/会话/操作事件；服务目录/实例；任务；区域/版本/适配矩阵/集成/凭据引用。列表支持搜索、部分状态筛选和详情定位。详情页签展示配置、关联记录与证据。技术方案弹窗解释候选链路、管理权与待确认事项。

装机、建群/接入、模板、维护、GPU 模式、配额、分配/交付/释放、告警、运维、服务、任务和设置操作均使用本地表单预检及计划预览，不改变业务数据或执行基础设施操作。确认框只是示例交互，不证明前置条件已满足。专业工具不打开真实端点。

## 本地文字批注

顶部进入标注模式，点击区块、表格列标题或详情字段输入文字；该模式拦截相关业务点击。技术方案弹窗内容也可标注（弹窗内有“标注此说明”入口）。批注栏支持修改、定位、导入/导出 JSON，删除需本地确认。

批注保存在当前浏览器与当前来源的 localStorage，key 为 s1-platform-notes-1；切换浏览器、端口或清理站点数据会影响可见性，请导出备份。不保存真实密码、密钥或其他敏感内容。导入合并并按 ID 去重，不覆盖已有批注。业务示例没有持久化。示例资产详情字段批注目前关联页面/页签/字段，不区分具体资产实例，适合评审页面结构，不适合生产对象审计。首轮仍以可标注区块为主体，不支持任意圈画。

## 边界

旧 prototypes/s1-console 保留。此原型覆盖产品信息结构与关键表单，不实现真实控制器调谐、业务审批、计费、终端、监控或任务执行。列表与详情记录为虚构，关联和状态只是讨论样例。技术方案均为候选，不证明兼容性与性能。监控图表明确标为固定示例，无实时数据。不同具体对象共享页面结构批注，不作为生产对象审计。
